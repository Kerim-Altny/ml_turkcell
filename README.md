# Makine Öğrenmesi Çalışmaları

Turkcell kurslarında yazdığım makine öğrenmesi kodları ve uygulamaları.

| Klasör | Konu |
|--------|------|
| `diyabet_tahmini` | Diyabet tahmini |
| `donmus_gol` | Donmuş göl |
| `dunya_su_kitlesi` | Su içilebilirliği (potability) analizi ve görselleştirme |
| `ev_fiyat_tahmini` | Ev fiyat tahmini |
| `kalp_krizi` | Kalp krizi tahmini |
| `musteri_segmentasyonu` | Müşteri segmentasyonu (OnlineRetail verisi) |
| `rakamlarin_goruntusu` | Rakam görüntüsü sınıflandırma |
| `robot_kesif` | Robot keşif |
| `urun_kumeleme` | Ürün kümeleme |

Her klasörde ilgili Jupyter Notebook (`.ipynb`) ve veri seti bulunur.

## Kullanım

```bash
pip install jupyter pandas numpy scikit-learn matplotlib
jupyter notebook
```
